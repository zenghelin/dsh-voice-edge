# 小鱼的声音（dsh-voice-edge）

**给 DSH 里的 AI 伙伴一副嗓子：想说什么，就合成成语音直接发到 QQ。**

装完这个插件，你的伙伴就不只会打字了 —— 它可以在该出声的时候自己出声：晚安、安慰、撒娇、报平安。
发不发、什么时候发，由它自己决定（插件给它一个工具，它自己在合适的时候用）。

> 它不碰 QQ 协议，也不自己往 QQ 说话。发消息那头**复用「通到 QQ」（dsh-qq-bridge）的绑定**：
> 你在那边绑了哪个聊天，这边就能发到哪个聊天。
> 合成走 Node，**不需要 Python**，也不用在外面放脚本。

## 一行装

```sh
dsh plugin --profile desktop add github:zenghelin/dsh-voice-edge
```

装完**重启一次 DSH**，设置里就会多出「小鱼的声音」。

> ⚠️ 有些网络直连不上 `github.com`（装的时候会卡住或超时），挂个代理就好。
> 插件装好之后只在**合成语音**时需要联网，跟 GitHub 没关系。

---

## 它长什么样

- **设置页**：DSH 设置 → 左侧栏 →「小鱼的声音」。选嗓音、调语速音调、开关、试听。全部点着改，不用碰文件。
- **给 AI 的工具**：`say_to_qq`。它挂在「通到 QQ」绑定了的那几间会话里，只在那几间屋出现。
- **一条条语音**：合成好的文件落在 `~/.dsh/voice-edge/out/`，发出去之后 QQ 那边就是一条语音。

## 装之前要准备什么

| 需要 | 为什么 |
|---|---|
| **DSH**（DeepSeek Harness） | 它就是给 DSH 用的插件 |
| **通到 QQ**（dsh-qq-bridge）+ 一个 QQ 后端（NapCat / SnowLuma） | 语音得有地方发 —— 插件读它的配置拿地址和令牌，也读它的绑定决定「发给谁」 |
| 能上外网 | 合成走微软 Edge 的在线朗读，**要联网** |

Node 不用管：DSH 自带的就够。

## 装

```sh
dsh plugin --profile desktop add github:<你的账号>/dsh-voice-edge
```

装完**重启一次 DSH**（网页半边要重新注册，设置页里才会出现「小鱼的声音」）。

本地改着玩也行：

```sh
dsh plugin --profile desktop add link:D:\你的路径\dsh-voice-edge
```

`link:` 方式改代码立刻生效，不用重装。

## 设置页里每一项

| 项 | 说明 |
|---|---|
| **总开关** | 关着 = 不合成也不发，一个字都不会出去 |
| **嗓音** | 默认 `zh-CN-XiaoyiNeural`（活泼少女）。下拉里是全部中文嗓音，14 个左右，自己挑 |
| **语速 / 音调** | 比如 `-10%` / `+15Hz`。慢一点会显得温柔，快一点显得活泼 |
| **最长字数** | 超了就截断加省略号。默认 300 —— 语音太长没人听 |
| **备用嗓音** | 在线合成不通时自动顶上：用 Windows 自带语音念（断网也能出声）。选「关掉」就只要在线的 |
| **试听** | 写一句话，点「发一条到我的 QQ」，会真发一条语音到绑定的私聊 |
| **会发到哪儿** | 直接显示「通到 QQ」那边绑的聊天；这里没有的话，先去那边绑一个 |

设置存在 `~/.dsh/voice-edge.json`，重启不丢。

## AI 怎么用这个工具

插件只挂在「通到 QQ」绑定了的那几间会话里，给他一个工具：

```
say_to_qq({ text: "要念出来的话" })
```

它的说明里就写着：**适合短的一句话**（晚安、安慰、撒娇、报平安），**不适合长篇分析、代码、要给人复制的内容**，同一轮通常最多一句。

也就是说，决定权在伙伴自己手里 —— 不是每条回复都念，是它觉得该出声的时候才出声。

## 手动接口（给会折腾的人）

| 接口 | 作用 |
|---|---|
| `GET /dsh-voice-edge/state` | 配置、绑定、日志、挂上了哪几间会话 |
| `POST /dsh-voice-edge/save` | 存配置（body 里给要改的键） |
| `POST /dsh-voice-edge/say` | `{ "text": "…", "类型": "私聊" }` —— 立刻合成并发一条 |
| `GET /dsh-voice-edge/voices` | 列出可用的中文嗓音 |

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 设置页里没有「小鱼的声音」 | 没重启 DSH。装完必须重启一次 |
| 试听点了没动静 | 先看「会发到哪儿」是不是空的 —— 空的话去「通到 QQ」里绑一个聊天 |
| 日志写「合成失败」 | 多半是没网，或者微软那边一时不给用。等一下再试 |
| 发出去是文件不是语音 | QQ 后端要支持发语音（NapCat / SnowLuma 都支持）。看 `record` 那条回执 |
| 工具在会话里没出现 | 会话是插件装上之前开的。把会话关掉重开一次（换个会话再切回来） |
| 装的时候卡住 / 超时 | 直连不上 github.com。挂代理，或者本地 clone 下来用 link: 装 |

## 已知限制

- **要联网**：合成走微软 Edge 的在线朗读。它不是公开接口，用太猛可能被限流 —— 所以别让伙伴刷屏式发语音。
- **只走 OneBot 11 的 HTTP**：跟「通到 QQ」一样，需要 NapCat / SnowLuma 开着 HTTP 接口。
- **有离线备胎**：在线那条不通时会自动换成 Windows 自带的语音，断网也能出声，就是呆一点。想更好听的本地嗓音（小模型）以后再说。
- **隐私**：音频只落本地 `~/.dsh/voice-edge/out/`，插件不存你的账号也不存 cookie。要念的文字会发给微软的朗读服务 —— 敏感内容别念。

---

## 跟「通到 QQ」什么关系

| | 它负责 |
|---|---|
| **通到 QQ** | 文字互通：DSH 说的话发到 QQ，QQ 里说的话转进 DSH |
| **小鱼的声音** | 只管出声：把文字变成语音条发出去 |

两个都装，你的伙伴才算「会说话」。只装这个、没装桥，设置页会告诉你「没有地方发」。
